# The Body Shop · Ocean Defence — Visual Merchandising 3D

Konsep tugas Retail Advertising / Visual Merchandising (mahasiswa). Bukan materi resmi The Body Shop.

Outlet mal 10 × 8 m bertema kelautan dengan focal point Sunscreen Island, dibuat sebagai halaman 3D interaktif (three.js).

- Buka `index.html` (atau situs GitHub Pages repo ini) di browser.
- Drag untuk memutar, scroll untuk zoom, klik kanan + drag untuk menggeser.
- Tombol **◎ Fokus props** menampilkan tiap props sendiri-sendiri (Etalase, Fasad, Window Display, dll).
- Bar kamera bawah berisi sudut pandang interior dan sudut sisi outlet.
