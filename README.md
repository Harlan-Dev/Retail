# The Body Shop · Ocean Defence — Visual Merchandising 3D

Konsep tugas Retail Advertising / Visual Merchandising (mahasiswa). Bukan materi resmi The Body Shop.

Outlet mal 10 × 8 m bertema kelautan dengan focal point Sunscreen Island, dibuat sebagai halaman 3D interaktif (three.js). Denah: `denah.png`.

## Tata letak
- **Kiri:** judul, peta mini (klik untuk menuju), Konsep & material, Musik toko.
- **Tengah:** tampilan 3D outlet.
- **Kanan:** Jelajah, Tampilan, Sudut kamera, kartu info props & keterangan tur.
- Tombol ‹ › di tepi tampilan 3D menyembunyikan/menampilkan panel. Di ponsel, panel menjadi laci.

## Cara menjelajah
- **Klik props** atau **titik bernomor** → kamera menuju props dan muncul kartu info (deskripsi, ukuran, material, produk).
- **▶ Tur otomatis** → kamera menjelajah 13 titik mengikuti alur belanja, dengan keterangan (bisa dijeda, maju/mundur).
- **⇡ Mode jalan** → jelajah sebagai pengunjung: WASD / panah, drag untuk menoleh, klik lantai untuk berjalan.
- **◎ Fokus props** → tiap props ditampilkan sendiri dan berputar.
- Drag: putar · Scroll: zoom · Klik kanan: geser.
